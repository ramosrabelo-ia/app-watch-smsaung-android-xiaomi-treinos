# treininhos

Aplicativo privado de treino em evolução, com versão atual V12 para Android e Galaxy Watch8.

## Apresentação interativa

A apresentação do projeto foi criada no formato Simbora Computer e está preparada na pasta `docs` para publicação pelo GitHub Pages.

Quando o Pages estiver habilitado em `main` e `/docs`, o endereço será:

https://ramosrabelo-ia.github.io/treininhos/

A apresentação mostra o produto, os quatro treinos, a experiência de uso, Health Connect, integração com Withings, Galaxy Watch8, evolução das versões e arquitetura do projeto.

## V12

A V12 está em `treino-da-luana/v12` e reúne quatro treinos conjugados, 44 imagens offline, progresso semanal, integração opcional com Health Connect e um aplicativo Wear OS 6 independente para o Galaxy Watch8.
