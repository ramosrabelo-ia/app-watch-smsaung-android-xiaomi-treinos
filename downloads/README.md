Os dois APKs usam o mesmo identificador de aplicativo e a mesma assinatura para permitir a comunicação pelo Wear OS Data Layer.

O APK do celular contém fotos, cargas, séries, progresso e integração opcional com o Health Connect. O APK do relógio contém a seleção dos treinos e os checks sincronizados.

Para preservar dados ao atualizar uma instalação existente, a nova versão precisa ser assinada com a mesma chave da versão instalada. Não publique chaves privadas no repositório.
